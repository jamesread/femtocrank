Table examples

Femtocrank tables are plain HTML with optional bordered, row-hover, and a responsive-cols wrapper around the table. Use col-priority-1 through col-priority-5 on matching th and td cells to hide lower-priority columns as the table narrows (1 is hidden first). Wrap wide tables in table-scroll to scroll horizontally instead. Add sticky-cols-1, sticky-cols-2, or sticky-cols-3 on the wrapper to pin the first columns while scrolling. Rows highlight on hover and when focus moves inside a row (for example, tabbing to a link or button in a cell).

Responsive columns

Add a responsive-cols wrapper around the table and the same col-priority-N class to each header and body cell in a column. Lower numbers hide first as the table width shrinks; leave essential columns (such as name and actions) unclassified.
